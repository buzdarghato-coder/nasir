NASIR SECURE VISION - APK BANANE KA TAREEQA (GitHub, free, ~5 minute)

1. github.com par free account banayen (agar nahi hai).
2. New repository banayen (naam: nsv-app, Private rakh sakte hain).
3. "uploading an existing file" par click karke is ZIP ke andar ki SAARI files/folders
   (android, www, package.json, capacitor.config.json, .github ...) drag-drop karein, Commit karein.
   (.github folder upload na ho to Add file > Create new file > naam: .github/workflows/build-apk.yml
    aur us mein build-apk.yml ka text paste karein.)
4. Repository ke "Actions" tab mein "Build Android APK" khud chalega (ya Run workflow dabayen).
5. Green tick aane par us run ko kholen, neeche "Artifacts" mein Nasir-Secure-Vision-APK download karein.
6. ZIP khol kar app-debug.apk phone mein bhej dein aur install karein
   ("Install unknown apps" allow karna parega).
